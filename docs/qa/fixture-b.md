# The page for the other pane

A split window is two documents, and photographing the same one twice proves nothing about either: a pane that failed to open would look exactly like a pane that opened correctly. So the second half of the window gets its own page, written the same way as the first — long paragraphs with no hard line breaks, so that the ink reaches the edge of the reading column and a program can tell where that edge is.

The point of the pair is difference. If a change makes the right pane narrower than the left, or starts its column somewhere else, or leaves it empty while the left one carries on working, the two measurements diverge and the run fails with the number that diverged. Reading two identical screenshots side by side would tell nobody anything.

## What this half carries

| In this pane | Why |
| :----------- | :-- |
| A table | The block that has come loose before |
| A quotation | Its rule sits on the column's left edge |
| A list | Markers belong on the axis too |

> A quotation here as well, because the two panes are measured by the same rules and a block that behaves in one of them and not in the other is exactly the kind of fault a single screenshot hides.

- The first item, long enough to reach the edge of the column so that the measurement of where that edge is has something to work with.
- A second, for the same reason.

That is all this page needs to be.
