# EPIC-MVP — Просмотр + редактор + оболочка

## Контекст

Первая рабочая версия MDViewer: двойной клик на `.md` → приложение открылось мгновенно и красиво, документ читается и редактируется live-WYSIWYG, есть вкладки, дерево папки, оглавление, поиск, сохранение. Решения зафиксированы: ADR-001 (Tauri 2 + CM6 live-preview), ADR-002 (Svelte 5), решения фаундера 2026-08-19 (live WYSIWYG как основной режим; плагины и экспорт — фаза 2, но архитектура их не блокирует).

**Детальное проектирование выполнено (2026-08-19, Fable 5):** `docs/design/` — ARCHITECTURE, IPC-CONTRACT, EDITOR-CORE, DATA-SAFETY, DESIGN-SYSTEM, HANDOFF-OPUS. Исполнение волн — строго по `docs/design/HANDOFF-OPUS.md` (там же детальные чеклисты каждой волны).

## Scope

**Входит:** каркас приложения, ассоциация `.md`, single-instance, live-редактор с рендерингом GFM, сохранение (атомарное) + автосохранение, поиск по файлу, TOC-панель, дерево файлов папки, вкладки, светлая+тёмная тема на токенах, session restore, сборки win/mac/linux в CI.

**НЕ входит (фаза 2):** plugin API, магазин/каталог тем, экспорт HTML/PDF, поиск по папке (заложен архитектурно — Rust crates уже выбраны), mermaid/KaTeX могут ехать в конце MVP при запасе времени.

## Декомпозиция задач (волны)

### MVP-0 — Каркас проекта

- **Приоритет:** P0
- **Модули:** Shell, UI
- **Preferred model:** sonnet
- **AC:**
  - [ ] `npm run tauri dev` открывает окно с hello-документом
  - [ ] Vite + TS strict + ESLint + prettier + cargo clippy настроены
  - [ ] CI: матрица win/mac/linux собирает bundle
  - [x] Выбран и зафиксирован UI-фреймворк — Svelte 5 (ADR-002)
- **Зависимости:** нет

### MVP-1 — Рендеринг и чтение (viewer-first)

- **Приоритет:** P0
- **Модули:** Editor Core, Reader Mode, Themes
- **AC:**
  - [ ] CM6 + lezer-markdown: GFM (заголовки, списки, чекбоксы, таблицы, код с подсветкой, цитаты, ссылки, картинки) рендерится live
  - [ ] Курсор в блоке раскрывает исходную разметку (магия Typora)
  - [ ] Типографика чтения: шкала, line-height, ширина колонки — по спеке Designer
  - [ ] Светлая + тёмная темы через токены; переключение мгновенное
  - [ ] Файл 5 МБ скроллится без лагов
- **Зависимости:** MVP-0

### MVP-2 — Файлы и данные

- **Приоритет:** P0
- **Модули:** Shell, Editor Core
- **AC:**
  - [ ] Открытие файла из argv / диалога / drag-n-drop
  - [ ] Ассоциация `.md`/`.markdown` в bundle; двойной клик открывает приложение с файлом
  - [ ] Single-instance: повторный двойной клик открывает файл в работающем экземпляре (новая вкладка)
  - [ ] Сохранение атомарное (temp+rename), Ctrl+S; индикатор несохранённых изменений
  - [ ] Автосохранение (настраиваемое) + восстановление несохранённого после крэша
  - [ ] Файл изменён извне → предложение перезагрузить (watch + конфликт с локальными правками)
  - [ ] Round-trip: открыл-закрыл без правок = байт-в-байт тот же файл
- **Зависимости:** MVP-1

### MVP-3 — Оболочка: вкладки, дерево, TOC

- **Приоритет:** P0
- **Модули:** Workspace, Outline

  - [ ] Session restore: открытые вкладки и активный файл восстанавливаются
- **Зависимости:** MVP-2

## Риски и допущения

- WebKitGTK-квирки на Linux → проверка на живом Linux до релиза (VM/WSL недостаточно для рендер-нюансов).
- «Магия Typora» в CM6-модели требует итераций UX (таблицы!) → при недостаточной магии — ADR-пересмотр в сторону Milkdown (заложено в ADR-001).
- Один разработчик-фаундер + агенты; волны строго последовательны.

## Метрики успеха

- Двойной клик → красивый документ < 1 сек.
- Ежедневное личное использование фаундером вместо Typora («я устал от маркдаунов» → больше не устал).
- 0 случаев потери/порчи данных.
