## Product

### Анализ

Ядро продукта: документ должен читаться как готовая вёрстка, а разметка — раскрываться только там, где пользователь работает. Это единственная фича, ради которой продукт существует.

### Industry-Standard Scope

Complete-standard live-preview (Typora/Obsidian): все узлы CommonMark+GFM рендерятся; курсор раскрывает исходник; таблицы — настоящие таблицы; картинки резолвятся относительно документа; подсветка кода ленивая.

**Вынесено сверх буквального запроса (включено):** гейт раскрытия по факту взаимодействия (а не по позиции курсора) — при открытии файла документ остаётся чистой читаемой страницей; это прямое следствие viewer-first позиционирования.

## Architect

### Ключевое решение

Раскрытие разметки включается по факту взаимодействия (`editingField` + `setEditing`), а не по позиции курсора. Программный `focus()` не считается взаимодействием. Диспатч эффекта на mousedown отложен на микротаск: раскрытие переформатирует строку, и сделать это в момент клика — значит увести текст из-под курсора до того, как CodeMirror разрешит позицию каретки.
