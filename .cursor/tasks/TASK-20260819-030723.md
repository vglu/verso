## Product

### Анализ

Каркас проекта: пустое, но уже красивое окно Tauri 2 + Svelte 5, с настроенными гвардами качества и CI на трёх ОС. Пользовательской ценности пока нет — есть фундамент, на котором волны MVP-1…5 не будут переделывать структуру.

### Industry-Standard Scope

Complete-standard каркаса десктопного приложения 2026: (1) сборка и hot-reload, (2) строгая типизация + линтеры + форматтер как гварды, (3) CI-матрица по всем целевым ОС, (4) конфигурация окна/бандла/ассоциаций/CSP, (5) дизайн-токены и тёмная тема ДО первого компонента (иначе потом переписывать всё), (6) анти-FOUC при старте, (7) типы IPC-контракта до реализации команд.

Сверх буквального запроса включено (дефолт — включить): анти-FOUC инлайн-скрипт темы, window-state плагин (геометрия окна), полный `lib/ipc/types.ts` заранее, i18n-словарь ru/en с первого дня, vitest-каркас, EmptyState как реальный экран (а не заглушка) — первое впечатление продукта.

Отрезано осознанно: иконка приложения (плейсхолдер, финальная — MVP-5 с Фантазёром), бандл-шрифты (см. решение в `### Решения`), e2e-тесты (фаза 2 по ARCHITECTURE §8).

### Затронутые модули

- Shell (Tauri 2, Rust): конфиг окна/бандла, плагины, single-instance, argv
- UI (Svelte 5 + Vite): каркас layout, EmptyState, сторы-заглушки
- Themes: полный набор токенов, светлая + тёмная
- DevOps: CI-матрица, скрипты качества

### Решения волны (Закон 5 — решение, а не вопрос)

1. **Шрифты:** бандл Inter/JetBrains Mono требует бинарной загрузки из сети. Решение: MVP-0 идёт на системном стеке (Segoe UI / SF / system-ui + Cascadia/Consolas/SF Mono), токены `--font-text`/`--font-mono` уже содержат его как fallback. Бандл-шрифты — задача MVP-1 (когда типографика документа станет видимой) через явную загрузку в `src/assets/fonts`. Риск нулевой: смена значения токена не трогает компоненты.
2. **Svelte 5 шаблон:** ставим вручную (vite + @sveltejs/vite-plugin-svelte + @tauri-apps/cli), а не `create-tauri-app` — интерактивный визард непригоден в автономном режиме, а структура всё равно наша (ARCHITECTURE §2).
3. **Иконки:** генерируем плейсхолдер-набор через `tauri icon` из простого SVG-глифа; финальная иконка — MVP-5.

## Designer

Экран волны — **EmptyState** (DESIGN-SYSTEM §5) + каркас layout.

- Layout-грид: `[sidebar 260px | main]`, main = `[tabbar 34px / content / statusstrip 26px]`. В MVP-0 sidebar и tabbar отрисованы как пустые поверхности правильных размеров и цветов (--bg-panel/--bg-app), контент — EmptyState.
- EmptyState: по центру глиф-логотип (SVG, `currentColor`, --fg-faint), заголовок 20px/600 --fg-ui, подпись --fg-muted, две кнопки (Открыть файл / Открыть папку) в стиле «тихая кнопка»: --bg-panel, border --border, radius-m, hover --bg-hover, focus-visible — кольцо --accent.
- Токены — полный набор DESIGN-SYSTEM §2; тёмная тема переопределяет только значения.
- Анимации: fade-in контента 200ms --ease при старте; reduced-motion → 0ms.

### Решения по ходу

1. Шрифты Inter/JetBrains Mono не забандлены (нет бинарной загрузки в среде) — работает системный стек из fallback-цепочки токена. Перенесено в бэклог 0.2, риск нулевой (значение токена).
2. `save_file_as` реализован в TS через JS-API dialog-плагина (`lib/ipc/dialogs.ts`), а не Rust-командой — плагин уже владеет нативным пикером. Поверхность контракта сохранена.
