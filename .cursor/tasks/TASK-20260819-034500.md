## Product

### Анализ

Редактор работает с чужими файлами. Конституционное требование: файл пользователя не портится никогда — ни при сохранении, ни при крэше, ни при правке извне.

### Industry-Standard Scope

Complete-standard (VS Code / Typora / Obsidian): атомарная запись; сохранение кодировки, EOL и BOM; детект внешних изменений с разрешением конфликта; восстановление после крэша; отказ от записи в формате, который не воспроизводится байт-в-байт.

### Acceptance Criteria

- [x] AC1: Сохранение атомарное (temp + fsync + rename)
- [x] AC2: Round-trip байт-в-байт: открыл-сохранил без правок = тот же файл
- [x] AC3: Черновики + восстановление после крэша
- [x] AC4: Внешнее изменение: чистая вкладка перечитывается, грязная предлагает выбор
- [x] AC5: Удаление файла извне не теряет содержимое
- [x] AC6: Single-instance end-to-end: второй двойной клик открывает вкладку в живом окне
- [x] AC7: Неподдерживаемая кодировка открывается read-only

### Edge Cases

- [x] EC1: Файл с BOM (UTF-8/UTF-16 LE/BE) сохраняется с тем же BOM
- [x] EC2: CRLF-файл остаётся CRLF; смешанные окончания сохраняют доминирующий стиль
- [x] EC3: Файл без завершающего перевода строки не получает его молча
- [x] EC4: Бинарный файл отклоняется с понятной ошибкой
- [x] EC5: Свой же save не вызывает ложного конфликта (эхо watcher игнорируется)
- [x] EC6: Блокировка файла антивирусом при rename — ретраи 50/150/400 мс

### Найденные и исправленные проблемы

1. **Авто-перезагрузка помечала вкладку изменённой.** Наша же программная запись в редактор возвращалась через `onChange` и выставляла `dirty`. Введён признак `userInitiated` (транзакция с `userEvent: 'input.reload'` не считается правкой). Закрыто регрессионным тестом `tests/editorHandle.test.ts`.
2. **JSON с BOM молча сбрасывал настройки.** `serde_json` отвергает BOM, а мы падали в дефолты и перезаписывали файл. Теперь BOM снимается перед разбором — иначе правка `settings.json` в Notepad обнуляла бы настройки пользователя. Закрыто тестом `json_with_utf8_bom_is_still_read`.

### Ограничение (принято осознанно)

Сквозной сценарий «напечатать → Ctrl+S» не проверен синтетическим вводом: в этой среде `SendKeys` блокируется UIPI. Путь записи покрыт композицией автотестов (декод → энкод → атомарная запись → сравнение байт) и ревью; рекомендуется 2-минутная ручная проверка фаундером.
