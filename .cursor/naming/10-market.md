# Verso: Позиционирование и выбор имени

**Дата:** 2026-08-19  
**Статус:** готово к решению

## 1. Позиционирование в одну фразу

**Markdown-просмотрщик Typora, который открывается за секунду, весит 2 МБ и никогда не испортит твой файл.**

Или короче:

**Оформленный Markdown, живой редактор, хранилище файла как сейф.**

---

## 2. Смысловые оси позиционирования

Продукт отличается по пяти независимым осям:

| Ось | Конкурент | Verso | Значение |
|-----|-----------|----------|----------|
| **Скорость** | Obsidian (долгий старт), MarkText (150 МБ) | Холодный старт < 1 сек, 2 МБ установщик | Для занятых, мгновенное открытие |
| **Целостность файла** | Все (молчаливо корректируют) | Атомарное сохранение, кодировка и переносы сохраняются байт-в-байт | Для тех, кто боится потерять данные |
| **Внешний вид** | Markdown-исходник | Живой предпросмотр (разметка только под курсором) | Читаешь документ, не исходник |
| **Контроль** | Typora (закрытая, платная) | Открытый код, MIT, никаких облаков | Полная независимость |
| **Вес** | Electron (150–300 МБ) | Tauri 2 + webview (40 МБ памяти) | Не тормозит систему |

**Метрика успеха:** установки + звёзды на GitHub (продукт бесплатный и открытый).

## 5. Требование фаундера: «просмотрщик И редактор»

Имя должно ясно показывать, что это оба. Варианты решения:

### 5.1 Имя само показывает оба

- **Leaf** — лист документа, который читаешь (просмотр) и правишь (редактирование). Естественно.
- **Echo** — эхо разметки; в процессе отзвука ты и правишь. Может быть неясно.
- **Silk** — гладко пишешь и читаешь. Нейтрально.

### 5.2 Имя + дескриптор (связка)

- **Leaf Editor** (явно редактор, но просмотр подразумевается)
- **Glimpse Reader** (явно просмотр, редактирование скрыто)
- **Silk Markdown** (указывает формат)
- **Echo Doc** (документ, подразумевает оба)

### 5.3 Рекомендация

**Выбрать имя, которое само работает на оба смысла, без дескриптора.** Дескриптор разбалтывает (Leaf Editor → длинно, Glimpse Reader → неточно). Лучше короткое, которое просится в разговор оба смысла.

**Формула для финалистов:**
- Основное имя (одно слово, 1–2 слога)
- Tagline: «Markdown viewer & editor for Mac/Windows/Linux»
- Вторичный слоган на сайте: «Reads like a document. Edits like a text file. Saves like a vault.»

## 7. Рекомендация

**Выбрать: LEAF**

### Обоснование:

1. **Смысл универсален.** «Лист документа» — понимают все, везде. Лист бумаги одновременно читают и правят.

2. **Ассоциация с жизнью и скоростью.** Leaf = листья дерева (живое, лёгкое, быстро колышется). Плюс намёк на speed (листья шелестят, как быстрый редактор).

3. **Работает для обоих смыслов без tagline.** 
   - Просмотр: листаешь документ (пролистываешь).
   - Редактирование: пишешь на листе.
   - Нет двусмысленности.

4. **Никак не занято в экосистеме редакторов.** Есть npm-пакеты с именем, но ни один не доминирует.

5. **Произносится, запоминается, живёт без объяснений.** Скажешь по телефону — сразу понимают.

6. **Даёт пространство для дизайна.** Логотип: лист (стилизованный, зелёный или чёрный), минималистичный, узнаваемый.

7. **Позиционирование просто:**
   - Основное: **Leaf: Markdown Viewer & Editor**
   - Tagline: *Read like a finished document. Edit in place. Safe as a vault.*
   - Вторичный: *Fast. Light. Yours.* (3 главных плюса: скорость, вес, открытость)

### Действия:

1. Зарезервировать `.app` домен (если свободен).
2. Переименовать репозиторий: `Verso` → `Leaf`.
3. Обновить README, docs, брэнд-материалы.
4. Запустить на GitHub / ProductHunt с этим именем.
